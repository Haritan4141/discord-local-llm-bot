Main Bot

PID: -

Register Guild Commands は `.env` の `GUILD_ID` に指定したサーバーへ登録します。反映は速めです。

Register Global Commands は全サーバー向け登録です。反映は遅めで、最大 1 時間ほどかかることがあります。

Start Bot は `node index.mjs` を GUI の子プロセスとして起動します。ログは `bot.log` にも追記されます。

Standby Bot

PID: -

Standby Bot は、メイン Bot を停止している間だけ同じ Bot で固定返信する待機モードです。

Main Bot と Standby Bot は同時起動できません。切り替えて使ってください。

追加の Discord Bot や別トークンは不要です。`DISCORD_TOKEN` をそのまま使います。
